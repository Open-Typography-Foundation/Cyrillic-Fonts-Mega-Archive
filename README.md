## 🏛️ О проекте (Overview)
Кириллическая письменность — одна из величайших типографических систем человечества, объединяющая более 250 миллионов носителей русского, украинского, белорусского, болгарского, сербского, македонского и среднеазиатских языков.

**Open Typography Foundation** под руководством основателя **Мохаммада Голамрабби (Mohammad Golamrabbii)** представляет масштабную коллекцию высококачественных открытых шрифтов с полной поддержкой кириллицы, соответствующих стандартам **SIL Open Font License 1.1** и **Apache 2.0**.

## 📂 6 Архитектурных категорий (6 Master Categories - 117 Fonts)

### 1. 🚩 01_Soviet_Constructivist_Retro_Poster (Конструктивизм и плакаты)
Авангардные плакатные шрифты в стиле Родченко, конструктивизма 1920-х годов и советской космической эпохи.
- **Шрифты:** Stalinist One, Russo One, Ruslan Display, Kelly Slab, Forum, Rubik Mono One, Seymour One, Podkova, Prosto One, Oi, Press Start 2P. (11 шрифтов)

### 2. 🏙️ 02_Modern_Cyrillic_Grotesque_Sans (Современный гротеск / UI Сан-сериф)
Чистые, нейтральные и высокочитаемые гротески для мобильных приложений, сайтов и операционных систем.
- **Шрифты:** PT Sans (полное семейство ПараТайп: Regular, Bold, Italic, Narrow, Caption), Golos Text, Onest, Exo 2, Jost, Jura, Play, Scada, Ruda, Arimo, Rubik, Montserrat, Oswald, Fira Sans, Geist. (53 шрифта)

### 3. 📜 03_Imperial_Classical_Literature_Serif (Классическая литература и антиква)
Благородные книжные антиквы для публикации классической русской литературы (Пушкин, Толстой, Достоевский), научных трудов и прессы.
- **Шрифты:** PT Serif (ПараТайп: Regular, Bold, Italic, Caption), Cormorant Infant, Oranienbaum, Old Standard TT, Alice, Prata, Lora, Tinos, Tenor Sans, Yeseva One, Spectral, Vollkorn, Playfair Display. (30 шрифтов)

### 4. ✒️ 04_Slavic_Traditional_Calligraphy_Cursive (Древнерусская вязь и скоропись)
Живые рукописные почерки, стилизации под полуустав и изящную скоропись.
- **Шрифты:** Marck Script, Bad Script, Neucha, Underdog, Caveat, Pacifico, Comfortaa, Lobster. (8 шрифтов)

### 5. ⚡ 05_HighCTR_YouTube_Media_Display (Медиа, Ютуб и акциденция)
Шрифты максимальной заметности для обложек видео, афиш и вирусных заголовков.
- **Шрифты:** Cuprum, Didact Gothic, Phudu, Stick, Rubik Dirt, Rubik Bubbles, Rubik Glitch. (8 шрифтов)

### 6. 💻 06_Developer_Coding_Monospace (Моноширинный код)
Терминальные шрифты с поддержкой кириллических комментариев и лигатур.
- **Шрифты:** PT Mono (ПараТайп), Fira Code Cyrillic, Source Code Pro, Lilex, Liter. (7 шрифтов)
